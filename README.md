# VOWOV

A xianxia cultivation browser RPG built with vanilla JavaScript, HTML5, and CSS3. Train, cultivate, explore the world, and encounter mysterious events (Kỳ Ngộ) on your path to immortality.

## Play

The game is designed for GitHub Pages deployment. Once deployed, you can play directly in your browser on desktop, tablet, or mobile.

## Features

- **Cultivation System**: Meditate and attempt breakthroughs as you progress through realms
- **Character Management**: Track your name, spiritual roots, physique, and progression
- **Exploration**: Discover the world and encounter random events
- **Kỳ Ngộ System**: Mysterious encounters with meaningful choices
- **Local Save**: All progress saved in your browser (localStorage)
- **Save Management**: Export/import your save data
- **Responsive Design**: Works on desktop, tablet, and mobile

## Development

The game uses ES modules and vanilla web technologies - no build step required. Just open `index.html` in your browser or deploy to GitHub Pages.

## Local Development

1. Clone the repository
2. Open `index.html` in a web browser (or use a local server)
3. Start playing!

## Save Data

Your game progress is stored locally in your browser. Use the Settings tab to export/import saves for backup.
