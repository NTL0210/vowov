# Artwork Assets

This directory is intended for AI-generated artwork for VOWOV.

Priority artwork to generate:
- Main menu/background (xianxia landscape with misty mountains)
- Cultivation chambers and meditation scenes
- Ancient ruins and hidden realms
- Spirit herbs and mystical artifacts
- Characters and spirit beasts
- Heavenly tribulations

If image generation tools are available, generate original artwork and place files here. Images should be optimized for web (WebP preferred where compatible) and used in the game.
